Model information

A concise view of the academic machine-learning implementation behind this wellness signal.

Prediction typeRegression

Estimates a continuous wellness score.

OutputWellness score (0-10)

The API returns the predicted score rounded to two decimal places.

Input featuresAcademic, lifestyle, stress and digital-habit information

Age, gender, country, academic level, platform, purpose of use, screen time, phone unlocks, study, physical activity, sleep and stress.

Machine-learning modelTuned Random Forest Regressor

Saved and loaded as the preprocessing-and-model pipeline Mental_Health_Model.pkl.

DatasetStudent Social Media And Mental Health Impact.csv

The project dataset used during model development.

Evaluation metricsTest R² 0.8650 · MAE 0.3689 · RMSE 0.4869

Reported in the project notebook for the tuned Random Forest model. Metrics are shown for academic context, not clinical validation.

Project context

About this project

An academic exploration of everyday wellness patterns and machine-learning prediction.

Problem

Students may find it difficult to understand how lifestyle, academic routine, digital habits, sleep, physical activity and perceived stress relate to overall wellness.

Approach

The project analyzes the information provided by the user and generates a wellness score with the existing prediction model.

Output

The application produces a wellness signal on a 0-10 scale and presents the result in an easy-to-understand format.

Purpose

This is an academic and informational project for exploring wellness-related patterns and machine-learning prediction. It is not a medical or clinical diagnostic system.

Important

A signal, not a diagnosis.

This prediction is for informational and educational purposes only. It is not a medical diagnosis or clinical psychological assessment. If you are concerned about your mental health, consider speaking with a qualified professional or someone you trust.
